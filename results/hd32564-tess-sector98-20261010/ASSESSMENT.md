# HD 32564: Sector 98 discovery screen

Sector 98 was opened as a separate discovery search after neither Sector 5 nor
Sector 32 produced a qualifying transit. This was not a frozen prediction test.
The plan records the prior cache state, source hashes and retained prior results.

QLP finished below threshold. Its strongest selected peak is 0.763938 days,
77 ± 19 ppm, with formal SNR 4.04. This peak is not a planet candidate.
The TESS-SPOC file request returned HTTP 404; the error is retained. Missing
SPOC data do not constitute negative transit evidence or independent confirmation.

Across the separately searched Sectors 5, 32 and 98, no qualifying transit
signal has emerged for HD32564 = TIC213078996. Each search uses its own short
baseline and the standard period limits. The data were not jointly searched
across years, long-period transit sensitivity was not established, and no
injection-calibrated depth or radius exclusion is justified. Planets with
nontransiting orientations remain possible. These results do not independently
confirm or refute the external RV interpretation and are not a novelty claim.
