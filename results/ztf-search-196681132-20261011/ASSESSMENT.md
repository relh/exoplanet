# TIC196681132: strongest exploratory ZTF peak does not validate

The strongest early-ZTF peak in the TESS-guided period interval is not convincingly repeated in the later reserved observations. This weakens that selected ZTF timing solution; it does not reject the original TESS signal or exhaust all possible ephemerides.

The design was recorded before fitting: use only HMJD<60000 for discovery,2049 trial periods spanning the preexisting TESS conditional interval0.7244189058–0.7245358083days, free phase and three durations around the frozen TESS duration. The658 quality-screened observations split into419 discovery and239 reserved points. Each ZTF object is normalized by its discovery-only median magnitude, with flux errors propagated from magnitude errors. No photometric outliers are clipped. Both subsets use the previously recorded assumed-UTC time conversion; that assumption remains conditional.

The discovery search selects P=0.7244915703days, epoch BTJD1199.1095601 and duration0.0384day. Its box-search selected formal SNR is8.91, not a trials-corrected significance. The ephemeris is saved in frozen.json before the later measurements are calculated. A separate weighted fit with object-specific intercepts gives discovery depth2.1507%±0.2420% formal error, with20 inside points across16 event numbers.

At that unchanged clock, the reserved fit gives0.3248%±0.2779%, formal SNR1.17, with17 inside points across17 event numbers. The inspected discovery/reserved fold plot does not show a convincing recurring reserved dip at the selected window. Residual chi-square is2320.26/415degrees of freedom in discovery and1095.12/235 in reserved data, so formal errors substantially understate the observed residual scatter. No calibrated false-alarm probability or physical classification is inferred.

Three deterministic controls add1%,2% and4% flux dips at the original TESS clock to the real observations and repeat the same split workflow. Their selected periods lie within1.65e−6 fractional error of the injected period, with modulo-epoch offsets below0.00412day. Their reserved formal SNR values are9.33,12.22 and16.75. These tests demonstrate that the workflow can recover added signals in this sampling; they do not establish completeness or an observed transit. In particular, selected injected depths exceed the added amplitudes, indicating contributions from existing data/noise at that phase. That is a follow-up clue, not independent recovery evidence. Any investigation prompted by these controls must disclose that the reserved observations have now been opened.

The group-intercept measurements are independently verified by weighted within-group centering rather than the design-matrix implementation. Input hashes, split and frozen ephemeris also pass verification. All49 repository tests passed in22.13seconds. Both plot panels were inspected. This exploratory phase search is distinct from testing the original frozen TESS predictions; source, time-scale and catalog-coverage limitations remain.

Next useful work can inspect the original TESS-clock phase and alternate ZTF peaks with explicit post-selection limits, or obtain genuinely new observations. Do not promote the current strongest peak to a planet candidate or count this analysis as independent validation.
