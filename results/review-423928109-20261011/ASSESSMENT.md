# TIC 423928109: known rotational-variable concern

The discovery-only screening passed at 9.934171 days, 571 ppm, formal box SNR 19.10, using sectors 15–17. Four events passed the event-support threshold. This is not a planet confirmation.

A successful 60-arcsecond VSX query returns Gaia DR3 2247178261373901440, classified ROT (OID 7771562). SIMBAD independently links that exact Gaia identifier and TIC 423928109 to the same object, TYC 4447-448-1. This establishes identity rather than merely a nearby positional match. VSX supplies no period, so no catalog period agreement is claimed.

The inspected discovery plot shows a broad depression and substantial positive excursions. The best sinusoidal fit has 0.995 times the box fit's likelihood improvement. Together with the catalog classification, this makes rotational variability a substantial concern. Remove this signal from new-planet priority; this does not exclude planets around the star or establish the physical origin of every dip.
