# TIC34576133 is the known variable BW Ari

The successful60-arcsec VSX query returns **BW Ari**, OID251794, type **BY**,
period **9.57days**. SIMBAD's identifiers for BW Ari include **TIC34576133**
exactly, alongside HIP13806 and Gaia DR3 129070265532645888. The identity is
not based only on proximity.

BY is a rotational-variable class; see the classification discussion in the
[ASAS-SN variable-star study](https://academic.oup.com/mnras/article/486/2/1907/5420510).
The catalog period is close to, but not identical to, our discovery/refined periods
9.364/9.378days. Together with the broad folded feature and surrounding variability,
this makes stellar variability a strong alternative to the apparent transit signal.
We remove this signal from new-planet priority. The catalog match does not exclude
all possible additional planets in the system or constitute a physical fit of spots.

TIC396160833's successful VSX cone returns no rows. This neither proves novelty
nor excludes an instrumental or stellar cause.

Queries, raw response paths and hashes are retained in `results.json` and
`identity.json`. All three response hashes/parses and the exact TIC-to-BW-Ari
identifier were verified in `verification.json`. This supersedes the preceding
report's provisional new-signal priority for TIC34576133.
