# TIC396160833: block-shuffle controls weaken priority

17 of48 shuffled discovery light curves produce maximum box-search power at least as large as the original. By block length the exceedances are6/16 (0.5day),4/16 (1day) and7/16 (2days). The unmodified existing null-controls routine operates only on the original discovery sectors18–19.

This peak is not rare within the chosen family of timing-disrupted data. Together with the background variations and unsuccessful nominal/profile follow-up checks, deprioritize it for new-planet follow-up. This is not proof of an instrumental origin, and broad ephemeris uncertainty still prevents complete exclusion of planetary models.

The controls preserve flux/error pairs and short contiguous runs within gap-separated segments, with deterministic seeds. They search the same full period/duration domain for a maximum. They do not apply every downstream screening gate. Block seams, disrupted longer correlations and retained signal fragments limit interpretation. The17/48 count is not a survey-wide false-alarm rate or probability that this is not a planet;16 draws per block length are a small diagnostic sample.

`verify.py` checks raw and code hashes, all48 permutation bijections and counts, reproduces the original search and independently reruns one control at each block length. The other45 outcomes are reconciled without rerunning them. No additional observing epoch was opened, and the scientific search code is unchanged.
