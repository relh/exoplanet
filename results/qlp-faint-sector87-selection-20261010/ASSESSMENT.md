# Sector 87: frozen metadata selection, photometry not started

Selected 375 unused stars in existing radius/noise order. Excluded 24,399 previous selections, 13,938 without Sector 87 products, and 110 without two sufficiently separated reserved sectors. The pool and all 156 archived coverage chunks were hash-verified. No selected star had cached QLP/SPOC photometry. The next step is a first-100 pilot with controls on the first three ranked targets. Independent epochs are reserved before photometry. New to this project is not proof of scientific novelty; dated catalog/archive limits apply.
