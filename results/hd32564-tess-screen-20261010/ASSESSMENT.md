# HD 32564: initial TESS transit screen

No qualifying transit signal was found in the frozen Sector 5 discovery data.
QLP's strongest box fit has formal SNR6.79; TESS-SPOC's has SNR4.70. Both are
below the unchanged diagnostic threshold of7. These reductions share the same
images and are not independent observations. Neither top-three list includes
the reported approximately2.5566day RV period.

The clean baselines are23.563days (QLP) and24.104days (TESS-SPOC). Although the
plan describes the screen's configured0.5–20day range, the existing algorithm
caps maximum period at baseline/2.5: actual upper limits were9.425 and9.642days.
Thus this run did not test the11,24or49day RV components. Median uncertainty
floors were133 and118ppm respectively. No injection-based transit-depth exclusion
was performed, and the detrending is not a stellar-rotation analysis.

Sectors32and98 remain reserved and were not opened. The target and every
reduction/sector cache were absent before discovery. A negative short-baseline
transit screen does not exclude low-inclination planets, smaller transits,
poorly sampled events or longer periods. No new discovery or validation claim.

HD32564 is TIC213078996, HIP23575 and Gaia3227308623164447616, cross-identified
through SIMBAD IDs after a coordinate cone query. An initial MAST filtered
query failed; a subsequent assertion requiring an HD field also failed because
the cone row lacks that field. Both errors are preserved. Matching used explicit
TIC, HIP and Gaia identifiers, rather than treating a positional neighbor as
certain. Full identity and MAST download provenance are retained in
