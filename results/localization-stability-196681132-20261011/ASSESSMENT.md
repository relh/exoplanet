# TIC196681132: window-dependent image moments

All22 raw event maps were measured with the existing background-subtracted positive-flux moment, using two halfwidths (2/3pixels) and windows centered at either the target or TIC196683452. No events were rejected. All four comparison panels were inspected and88 calculations were reconstructed exactly.

Target-centered windows put22/22 estimates closer to the target for either size. Neighbor-centered windows put only13/22 and17/22 closer to the target. The measurements shift toward their chosen windows, with event15 particularly sensitive. This exposes truncation/background/positive-clipping dependence; the counts are not host probabilities. The raw target-region feature remains worth investigating, but this simple moment analysis cannot provide a calibrated neighbor exclusion.

No PRF model, registration uncertainty, correlated-noise calibration or proper-motion update was included. The next useful localization step is a scene-response fit with explicit competing sources and alignment/injection controls, not more equivalent moment comparisons. A target-host eclipse would still require physical classification; localization alone does not validate a planet.
