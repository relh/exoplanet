# Sector 91 frozen metadata selection

Selected 366 unused stars from the remaining inventory, preserving the existing radius/noise ranking. All prior selections including the complete Sector 87 sample are excluded. The pool and 156 archived coverage chunks were hash-verified; no selected target had cached QLP/SPOC photometry. Independent epochs are reserved before opening discovery data. No Sector 91 photometry has been opened by this selection; the first 100 targets will form a pilot before expansion. New to this search is not a novelty or completeness claim.
