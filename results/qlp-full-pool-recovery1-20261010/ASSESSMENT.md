# First full-pool data recovery

73 errors were frozen from the in-progress search before this recovery began.
68 targets became searchable using the single usable sector from their originally
assigned QLP training pair:65 below threshold,3 flagged, zero non-crowding review
passes. This does not add68 new unique targets to the selected survey.

Five targets (155176970,358657943,404739185,55278463,88772404) have no usable
assigned QLP sector. SPOC products for both assigned epochs returned404; errors
are retained. These are unsearchable cases, not planet nondetections. Later errors
from the running main campaign are outside this frozen recovery cohort.

Reserved epochs remain unopened by this workflow. Single-sector searches have
shorter baselines and a correspondingly lower period ceiling min(20,baseline/2.5);
this is not equivalent coverage to the planned adjacent-sector search. Empirical
uncertainties, where used, are explicit and are not calibrated red-noise errors.
Original errors, per-sector probes, successful results, script/source hashes and
raw-data URL/SHA provenance are retained in this directory and the main campaign.
