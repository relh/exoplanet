Scientific plots were generated by this project from the credited measurements unless a report states otherwise. Dependency and external-method citations remain in the run records. Raw downloads are kept outside Git in ignored data directories, with retrieval URLs, timestamps and SHA-256 hashes recorded in experiment manifests.

The release removes authentication query parameters from saved signed download URLs. Retained object identities and observation metadata describe the same products, but a stripped URL may not itself allow download. Query the provider's public archive for a fresh authorized link; the original raw-content hashes remain the reference.
